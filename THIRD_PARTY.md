# Third-party material

This package was written for the author's own projects. Some skills build on other people's work. Each such
skill carries a `THIRD_PARTY.md` in its own folder, and a `LICENSE` file when text or code was copied. This file
gathers those notes. It is generated by `tools/build_third_party.py`; edit the note in the skill folder, then run
the script.

Material that was copied keeps its own license and notice, and that notice travels with any copy of the skill.
Everything else is credited as a source of method, values or inspiration, and no code or text was copied.

## `integrity-audit` (scicraft)

Source note: [`plugins/scicraft/skills/integrity-audit/THIRD_PARTY.md`](plugins/scicraft/skills/integrity-audit/THIRD_PARTY.md)

None. Every file in this skill is original to this package or the author's own code.

- `references/audit-protocol.md` is original to this package. It is written from the author's own audit rounds
  (a Methods fact-check against code, a merged-supplement review, a manuscript section fact-check, a defense-report
  review, a bibliography audit, a figure audit). Its splits, kinds of finding, verdict words, hand-back format and
  briefs come from those records or were chosen for this package. It shares with common auditing practice these
  general ideas: reviewers who see only the sources, an independent second check that tries to refute each
  finding, a quote and a location for every finding, marking which findings rest on a script and which on
  judgment, and a fresh round after fixes.
- The reference-audit verdicts (`OK`, `FIX`, `REPLACE_IN_TEXT`, `QUERY`; `FIT`, `WEAK`, `WRONG`, `SELF`), the
  figure verdicts (`OK`, `FIX`, `DECIDE`) and the claim verdicts (`TRUE`, `NARROWER`, `FALSE`) are the author's own,
  from the author's audit briefs. The weights (`blocker`, `fix`, `polish`), round verdicts and re-audit words were chosen
  for this package.
- `scripts/remote_zip.py` is the author's own code, ported with an argument parser, digests, a byte comparison, a
  CRC check and a guard against servers that ignore range requests.
- `scripts/extract_numbers.py` was written for this package. Its `--diff` mode uses the numeric-token regex of the
  author's own merge safety net.

## `representation-probes` (scicraft-ml)

Source note: [`plugins/scicraft-ml/skills/representation-probes/THIRD_PARTY.md`](plugins/scicraft-ml/skills/representation-probes/THIRD_PARTY.md)

No third-party code. Every script is the author's own work, ported and generalized:

- `scripts/probes.py` ports `linear_cka`, `knn_overlap`, `mantel`, the noise-floor and retrieval block of a
  quality function, `direction_agreement` and the ridge redundancy and informativeness block from the author's
  analysis package for a dataset-embedding study, with the logic unchanged. The command-line interface,
  `monotonicity`, `parity` and `selftest` are new.
- `scripts/capture.py` generalizes the author's forward-hook code from the same study's encoder module
  (detach, clone, return None); the context manager, `compare` and the selftest are new.
- `scripts/cluster.py` ports the author's graph-clustering module from a self-supervised encoder project
  (cosine k-NN, Jaccard on the k-NN edges, Leiden with a GPU then CPU backend, the degeneracy guard, the
  isolated-node fill, resolution bisection, reference centroids, numpy ARI and NMI). The command-line interface,
  the logging that prints each backend message once, and the selftest are new.
- The `content_shuffle` snippet in `references/extraction.md` is copied from the same module.

Published methods implemented from their papers (formulas, no code copied): linear CKA (Kornblith, Norouzi, Lee
and Hinton, ICML 2019), the unbiased HSIC estimator (Song, Smola, Gretton, Bedo and Borgwardt, JMLR 2012), and the
Mantel permutation test (Mantel, Cancer Research 1967), the PhenoGraph graph construction (Levine et al., Cell
2015) and the Leiden algorithm (Traag, Waltman and van Eck, Scientific Reports 2019).

Libraries imported at run time, not copied or redistributed: python-igraph (GPL-2.0 or later), leidenalg
(GPL-3.0 or later), and optionally cugraph, cudf and cuml (Apache-2.0) and pynndescent (BSD-2-Clause). A user
who redistributes a program that links leidenalg takes on its license terms.
